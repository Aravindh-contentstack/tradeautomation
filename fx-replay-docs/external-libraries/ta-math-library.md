# ta‑math Library

> **Namespace:** `ta`\
> All functions expect plain JavaScript arrays (`number[]`).\
> **Return type:** **Array vs. last value:**\
> All functions above produce the **complete calculated series**.\
> If you only need the latest point, pick the last element:\
> `const lastRsi = ta.rsi(close, 14).at(-1);`
